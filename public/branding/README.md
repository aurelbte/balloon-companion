# Identité Balloon Companion

Le logo actuellement utilisé par l’application est temporaire. Cette zone
accueillera les futurs éléments officiels de l’identité de marque sans coupler
leur évolution aux composants d’interface.

Le futur logo devra être :

- très simple ;
- immédiatement identifiable à 32 px ;
- cohérent avec le langage visuel du Hero Ring ;
- compatible avec le mode sombre ;
- utilisable comme icône de la PWA sur iPhone, Android et navigateur.

Aucune proposition graphique n’est définie à ce stade.
